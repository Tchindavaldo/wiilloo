# Page IA Chat

## Description
La page IA Chat (`IAChatScreen`) offre une interface de conversation complète avec un assistant IA intelligent pour aider les étudiants dans leurs apprentissages.

## Fonctionnalités
- **Conversation en temps réel** avec l'assistant IA
- **Importation d'images** depuis galerie ou appareil photo
- **Pièces jointes** multiples avec aperçu
- **Indicateur de frappe** animé
- **Historique des conversations** avec accès rapide
- **Messages pré-chargés** pour démonstration
- **Timestamps** intelligents pour chaque message

## Interface
- **Header** avec informations sur l'IA et ses capacités
- **Zone de chat** avec bulles de messages stylisées
- **Barre de saisie** avec boutons d'action
- **Zone d'aperçu** pour les images sélectionnées

## Capacités de l'IA
- Mathématiques et physique
- Corrections d'épreuves
- Explications personnalisées
- Support multilingue

## Options disponibles
- **Historique** : Accès aux conversations précédentes
- **Pièces jointes** : Photos, galerie, fichiers
- **Effacer conversation** : Reset du chat
- **Paramètres IA** : Configuration (à implémenter)
- **À propos** : Informations sur l'IA

## Interactions
- **Envoi de message** : Texte + images
- **Réponses IA** : Simulées avec délai réaliste
- **Gestion des images** : Sélection, aperçu, suppression
- **Navigation fluide** : Auto-scroll vers les nouveaux messages

## Design
- Bulles différenciées (utilisateur/IA)
- Animations fluides
- Feedback haptique
- Interface moderne et responsive
